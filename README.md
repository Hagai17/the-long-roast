A one-sentence satirical roast of the lawmakers who regulate AI, crypto and the internet without being able to convert a file to PDF. Fourteen candidate sentences were drafted, verified by script to be exactly one sentence of at most 320 characters, and duelled pairwise on the bounty judge's own criteria — a real turn from authority to the unconvertible file, aim kept on power and competence, a quotable single pass with the punch on the last few words, and a specific detail over a worn cliché. The winner and the duels are recorded in `candidates.md`; the program writes the winning sentence to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
